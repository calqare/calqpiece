# CALQ Grand Line Formula Atlas

An interactive 3D pirate-themed math learning experience built with Three.js. Sail a ship across a Grand Line-style ocean, visit islands representing different math subjects, and battle enemy ships in quiz challenges.

## Features
- Fully 3D animated ocean, ships, and islands (Three.js)
- Sidebar menu of subjects/topics with quiz tracking
- Click-to-sail navigation with a cinematic follow camera
- Quiz battles triggered by clicking enemy ships

## Running it
This is a single self-contained HTML file — no build step required.

1. Clone or download this repo.
2. Open `index.html` directly in a browser, **or**
3. Enable GitHub Pages (Settings → Pages → deploy from main branch) to host it live.

## Tech
- Three.js (loaded via CDN)
- Vanilla JS, HTML, CSS
- Google Fonts (Pirata One, IM Fell English, Special Elite, Merriweather)
